# A-Feasibility-Aware-LLM-Framework-for-Navigation

To use the file, crazyflie is required to run the real test, or using crazysim to run the simulation.

llm_drone_control.py is used for running 1 drone for tasks, settings are in the beginning of the file

llm_multi_control.py is used for multiple drones for tasks, also enables communication of agents, you can change this in the settings

For both files, turn on DRY_RUN in the setting area to run LLM generation only, in this mode, no simulation or actuation will happen, the purpose of this mode is to test the result generated by LLM

2 tasks availble for all the drone settings
- "goto": The objective of the drone is moving from a point to another
- "tour": The objective of the drone is visiting a list of points in arbitary order
